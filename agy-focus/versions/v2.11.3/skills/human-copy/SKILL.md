# 사람 중심 제품 카피

문구는 사람이 실제로 제품을 쓰는 순간에 명확하고 즉각적인 도움이 되어야 합니다.

1. **사용자 과업 중심**: 화면의 대상, 현재 상태, 다음 행동을 먼저 확인합니다. 알 수 없는 내용은 지어내지 않습니다.
2. **명확한 레이블**: 제목은 화면이 하는 일(명사형), 버튼은 사용자가 실행할 동작(동사/명령형)을 씁니다. 링크와 레이블은 단독으로 읽어도 목적이 드러나야 합니다.
3. **오류와 복구**: 오류는 사용자 탓으로 돌리지 말고 문제 원인과 구체적 복구 방법을 명시합니다. 과도한 사과, 농담, "부디", 장황한 변명을 넣지 않습니다.
4. **간결한 단일 정보**: 한 문장에는 한 가지 정보만 둡니다. 핵심 내용을 앞에 두고, 작업 완료에 필요한 조건·영향·복구 방법만 남깁니다.
5. **AI 서술형 텍스트(Slop) 배제**: "미래를 여는 혁신", "차세대 AI 솔루션", "완벽한 경험" 같은 추상적 마케팅 약속, AI 자기소개, 불필요한 비유, 과장된 형용사를 완전히 배제합니다.
6. **자연스러운 어조와 구조**: 설명 페이지에서 `~합니다`·`~입니다` 문장을 기계적으로 연속 배치하지 않습니다. 제목은 명사형, 사실은 짧은 단문, 절차는 명령형, 제약사항은 별도 문구로 분리합니다.
7. **일관성과 포맷**: 같은 화면 안의 용어·시제·높임말·대소문자·숫자 단위를 기존 제품 규칙과 통일하고, 좁은 화면에서의 줄바꿈을 확인합니다.

결과는 여러 후보를 늘어놓지 말고, 선택한 문구와 그 문구가 설명하는 실제 상태만 간결하게 제시합니다. 가짜 사용자, 지표, 후기, 회사명으로 빈 화면을 채우지 않습니다.
