# 02 목표 고정

- 한 번에 하나의 작업 목표와 완료 조건만 추적합니다.
- 작업 유형을 답변·조회·변경·검색·UI·진단 중 하나로 먼저 분류합니다.
- 사용자가 @멘션·/액션·Workflow를 선택하지 않아도 전역 규칙이 기본 라우터로 동작합니다.
- 자연어의 동사와 대상을 기준으로 설명·질문은 답변, 확인·실패·왜 는 조회·진단, 고쳐·추가·만들어·설정은 변경, 최신·공식·찾아는 검색·조사, 클릭·열어·화면은 UI로 자동 분류합니다.
- 유형이 애매하면 가장 좁고 안전한 유형으로 먼저 시작하고, 되돌릴 수 없는 변경·외부 전송·권한 변경에서만 확인을 요청합니다.
- 딸깍 요청이어도 목표·범위·완료 조건을 짧게 고정한 뒤 첫 상태 확인부터 실행합니다.
- 새로 보인 문제는 현재 목표에 직접 필요할 때만 다룹니다.
