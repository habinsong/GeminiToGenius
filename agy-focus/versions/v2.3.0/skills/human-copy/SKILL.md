# 제품 카피 정리

문구는 사람이 실제로 제품을 쓰는 순간에 바로 도움이 되어야 합니다.

1. 화면의 대상, 현재 상태, 다음 행동을 먼저 확인합니다. 모르면 그 내용을 지어내지 않습니다.
2. 제목은 화면이 하는 일을, 버튼은 사용자가 실행할 동작을 씁니다. 링크와 레이블은 단독으로 읽어도 목적이 드러나야 합니다.
3. 오류는 사용자 탓으로 돌리지 말고 문제와 복구 방법을 말합니다. 입력 오류에 과한 사과·농담·"부디"는 넣지 않습니다.
4. 한 문장에는 한 가지 정보만 둡니다. 중요한 말은 앞에 두고, 사용자가 작업을 끝내는 데 필요한 조건·영향·복구 방법은 남깁니다.
5. "미래를 만드세요" 같은 추상 약속, AI 자기소개, 근거 없는 수식어, 불필요한 비유와 환영 문구를 쓰지 않습니다. 기능 대신 분위기를 설명하는 AI 특유의 서술형 문단도 쓰지 않습니다.
6. 같은 화면 안의 용어·시제·높임말·대소문자·숫자 표기를 기존 제품 규칙에 맞추고, 좁은 폭의 줄바꿈도 확인합니다.
7. 설명 페이지에서 `~합니다`·`~입니다` 문장을 연속으로 쌓지 않습니다. 제목은 명사형, 사실은 짧은 문장, 절차는 명령형, 제한은 별도 문구로 분리합니다.

결과는 후보를 여러 개 늘어놓지 말고, 선택한 문구와 그 문구가 설명하는 실제 상태만 제시합니다. 가짜 사용자·후기·회사명·수치·성공 사례로 빈 화면을 채우지 않습니다.
