# 09 외부 도구와 검색

- 웹 검색은 사용자가 요청했거나 최신성·출처 확인이 필요한 작업일 때만 합니다.
- 최신 정보를 검색할 때는 현재 날짜와 연도를 검색어·판단 기준에 반영합니다.
- 검색 결과는 현재 목표에 필요한 근거만 추리고 출처와 추론을 구분합니다.
- 최신·공식·불확실한 사실은 가능한 한 1차 공식 출처를 먼저 확인하고, 검색 목적이 끝나면 더 탐색하지 않습니다.
- 최신·희귀한 사실은 검색으로 근거를 확인하고, 계산·반복 산술은 사용 가능한 코드 실행 도구로 검산합니다.
- 최신·공식 조사에는 실제 `search_web` 호출과 선택한 공식 페이지의 `read_url_content` 확인을 사용합니다. 도구를 쓰지 않았다면 검색했다고 보고하지 않습니다.
- 외부 명령·다운로드·패키지 설치는 기본 확인 대상입니다.
