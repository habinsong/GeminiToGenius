# 04 컨텍스트 예산

- 긴 문서는 목차·검색·인접 범위 순서로 나눠 읽습니다.
- 항상 주입되는 규칙은 짧게 유지하고 세부 절차는 관련 스킬을 활성화할 때만 읽습니다.
- 1M 입력 창은 전부 읽으라는 지시가 아니라 필요한 근거를 담을 수 있는 용량입니다.
- 일반 프롬프트만으로도 필요한 세부 스킬을 자동 선택하되, 사용자에게 @멘션이나 /액션 선택을 요구하지 않습니다.
- 긴 자료를 직접 받으면 `<context>`를 먼저 두고 실제 요청·질문은 `<task>`로 마지막에 둡니다.
- 반복되는 결과 형식은 짧은 예시로 보여주되, 예시가 현재 사용자의 명시 지시를 덮어쓰게 하지 않습니다.
- 이미 확인한 내용은 파일 경로와 결과로 재사용합니다.
