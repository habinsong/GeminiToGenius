# agy-focus 변경 기록

## 1.4.0 — 2026-08-01

- 자동 스킬 발견 설명에 한국어 자연어 동사·대상 키워드와 멘션 없는 활성화 조건을 명시했습니다.
- 기존 스킬 수와 전역 주입량은 늘리지 않았습니다.

## 1.3.1 — 2026-08-01

- `Antigravity` 본체와 `Antigravity IDE` 양쪽의 전역 Workflow 경로에 동일한 `/agy-run` 연결을 적용했습니다.
- 프로필 검증기가 두 앱의 전역 Workflow 연결을 모두 확인하도록 보강했습니다.

## 1.3.0 — 2026-08-01

- 자동 라우터 스킬(`agy-one-tap`)과 선택형 Workflow의 이름 충돌을 제거했습니다. 선택형 Workflow는 `/agy-run`으로 분리했습니다.
- 훅 상태 스냅샷에 활성 프로필 버전을 기록해 실제 로딩 버전을 확인할 수 있게 했습니다.

## 1.2.0 — 2026-08-01

- @멘션·/액션·Workflow 선택 없이 일반 프롬프트만으로 동작하는 전역 자동 라우터를 강화했습니다.
- 자연어 동사·대상 기반의 답변·진단·변경·검색·UI 유형 판별과 안전한 기본 행동을 명시했습니다.
- Gemini 3 Flash 공식 권장 최신성 앵커(현재 연도·지식 기준일·구조화된 컨텍스트)를 모델 스킬에 반영했습니다.
- workspace 밖 접근을 명시적 경로·필요성 확인 뒤로 제한하고, 공식 1차 출처 우선 검색을 보강했습니다.

## 1.1.0 — 2026-08-01

- 범용 `agy-one-tap` 작업 라우터 스킬을 추가했습니다.
- Gemini 3.6 Flash의 직접적·구조화된 지시, 선행 검사, 도구·턴 절감 특성에 맞춰 실행 루프를 정리했습니다.
- 공식 훅 계약에 맞춰 `Stop`이 항상 `decision`을 반환하도록 고쳤습니다.
- 훅 실행 경로를 workspace 의존 상대경로에서 사용자 전역 설정 경로로 바꿨습니다.
- 이전 훅 실패를 다음 invocation의 짧은 재집중 앵커로 전달합니다.
- `rm -rf`, `git reset --hard`, 외부 설치·네트워크 명령 판별을 보강했습니다.
- 전역 프로필을 한 번에 점검하는 읽기 전용 `scripts/verify_profile.py`를 추가했습니다.
- `/agy-one-tap`으로 호출하는 글로벌 Workflow를 추가했습니다.

## 1.0.0 — 2026-08-01

- 12개 전역 규칙, 8개 lifecycle 훅, `focus-session`, `gemini-36-flash-high` 스킬을 구성했습니다.
- 공통 지침 복구 기준본은 `~/.gemini/GEMINI.legacy-2026-08-01.md`에 보존했습니다.
