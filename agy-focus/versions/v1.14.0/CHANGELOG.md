# agy-focus 변경 기록

## 1.14.0 — 2026-08-01

- 고정된 시각 스타일 강제값(모서리·테두리·그림자·대비)을 제거했습니다.
- 도메인 근거 없는 어두운 관제 화면·우주·로봇·가짜 지표·범용 AI 화면을 금지하는 검증 게이트를 추가했습니다.
- 비대칭·오프그리드·Command Bar·점진적 공개를 강제값에서 선택 기준으로 낮췄습니다.
- 키보드 포커스·색상 의존·불필요한 상호작용 움직임을 접근성 검증 대상으로 명시했습니다.
- 공식 모델 ID `gemini-3.6-flash`와 동적 Thinking 기본값·지원 레벨 최신성을 반영했습니다.

## 1.13.0 — 2026-08-01

- 반응형 웹 구현에 모바일 최솟값 우선·수직 흐름·`min-width` 확장 규율을 추가하고 데스크톱 선작성 후 `max-width` 축소 안티패턴을 차단했습니다.
- `clamp()` 유체 타이포그래피·여백, intrinsic sizing, 오버플로우 관리, 카드 중첩 해체, 비대칭 off-grid 확장 규칙을 반응형 검증 게이트로 내렸습니다.
- `Inter`·`Roboto`·`Arial` 무근거 기본값과 회색+보라/파랑 네온 팔레트를 막고, 의미 있는 OKLCH 토큰·틴트·fallback·1px 테두리·목적 있는 오프셋 그림자를 우선하도록 보강했습니다.

## 1.12.0 — 2026-08-01

- intrinsic sizing(`fit-content`, `min-content`)과 비대칭 off-grid·레이어드 겹침·서로 다른 비율을 시각 중심 UI의 기본 검토 대상으로 추가했습니다.
- 12px~16px 라운드 카드·소프트 그라데이션·부드러운 섀도우 대신 0px 모서리·1px 단색 테두리·고대비·의도 있는 오프셋 표현을 우선하도록 보강했습니다.
- 좌측 카피·우측 캡처 관습을 벗어난 `clamp()` 유체 타이포그래피·에디토리얼 구조와, 카드·고정 사이드바를 줄이는 여백 기반·Command Bar·맥락형 메뉴 중심의 점진적 공개 규칙을 추가했습니다.
- 기능 발견·반응형·키보드 접근성을 해치는 비대칭·겹침·숨김 명령은 단순화하도록 안전 조건을 함께 넣었습니다.

## 1.11.0 — 2026-08-01

- UI·웹 작업에 AI Slop·AI SaaS·모호한 헤드라인·서술형 텍스트·추상적 카피와 이미지를 금지하는 출력 기준을 추가했습니다.
- 목적 없는 효과·Hover·마이크로 인터랙션, 요술봉 같은 추상 아이콘, 장식용 다채로운 또는 보라색→파란색 그라데이션, 작위적인 AI 3D 일러스트를 차단했습니다.
- 자유분방하거나 기계적인 레이아웃, 동일 여백·모서리 반경을 반복하는 카드형 구성, 무근거 `Inter` 기본값을 피하고 실제 기능과 시각적 위계를 우선하도록 기본 라우터와 Gemini 스킬을 보강했습니다.

## 1.10.0 — 2026-08-01

- 공식 Skills 문서의 자동 선택 기준인 `description`에 실제 사용 문장인 `웹 페이지 만들어줘`, `아이디어 있는데 계획하고 코딩해봐`, `이 기능 고쳐줘`, `최신 공식 문서 찾아줘`를 직접 반영했습니다.
- 일반 한국어 프롬프트가 멘션·슬래시·수동 스킬 선택 없이 기본 라우터를 찾는 신호를 보강했습니다.

## 1.9.9 — 2026-08-01

- 자연어 아이디어 구현 테스트에서 내부 계획 제목을 실제 파일처럼 보고한 불일치를 확인했습니다.
- 보고 직전 파일 존재·비어 있지 않음과 실제 실행 명령을 대조하고, 내부 계획·임시 UI 제목을 파일로 보고하지 않는 완료 게이트를 추가했습니다.

## 1.9.8 — 2026-08-01

- API 설정 검토 프롬프트에서 Gemini API/SDK 세부 규칙이 자동 스킬 선택에 드러나지 않는 것을 확인했습니다.
- `gemini-36-flash-high` 설명에 API/SDK·모델 마이그레이션·deprecated sampling·thinking 설정 키워드를 추가해 멘션 없는 자동 활성화를 보강했습니다.

## 1.9.7 — 2026-08-01

- 최신 Gemini 3.6 Flash 공식 문서의 API 변경을 반영했습니다.
- Gemini API/SDK 코드를 다룰 때 deprecated 된 `temperature`·`top_p`·`top_k`를 제거하고 `thinking_budget` 대신 `thinking_level`을 사용하도록 안내합니다.
- Antigravity UI 모델 선택과 무관한 API 규칙은 API 작업에서만 적용하도록 범위를 제한했습니다.

## 1.9.6 — 2026-08-01

- v1.9.5 IDE 재작성본에 공식 `hooks.json` 본문에 없는 `continue_on_error`와 `event:` 필드가 남는 것을 확인했습니다.
- 재작성 지시에 공식 스키마 필드(`enabled`, 이벤트명, `type`, `command`, `timeout`)를 명시하고 해당 오염 필드를 차단했습니다.

## 1.9.5 — 2026-08-01

- 공식 조사 게이트를 2회 재작성까지 허용하고, 재작성 지시를 canonical Hooks 페이지의 실제 이벤트·필드명 기준으로 구체화했습니다.

## 1.9.4 — 2026-08-01
