# 3.0.1 검증 범위

확인일: 2026-10-16. 이 문서는 하네스 구현·패키지·설치의 검증과 실제 모델 품질을 구분합니다. 3.0.0의 모델 비교 결과를 새 규칙의 개선 효과로 재사용하지 않습니다.

## 구현과 직접 실패 경로

| 보호 | 확인 방법 |
| --- | --- |
| 빌드와 필수 시험 | 실제 컴파일 실패 때 시험을 차단하고, 문법 정상/없는 API·필드·함수 참조는 실제 호출에서 실패시킵니다. 정상 수정 뒤 PRD 세 시험과 증명서 재현을 확인합니다. |
| 오래된 성공 | 제품 입력·PRD 변경과 빌드 재실행 뒤 이전 시험 성공을 무효화합니다. |
| 필수 시험 누락 | 다른 시험이 통과해도 필수 ID가 실제 성공 목록에 없거나 skip/expectedFailure이면 실패합니다. 조기 종료와 오래된 캐시도 대조합니다. |
| 환경과 비교 | 현재 실행기·채점 조건과 시간 제한이 없거나 다르면 비교를 차단합니다. 조건 일치를 원격 모델·자원 집행·실사용 적합성으로 확대하지 않습니다. |
| 비판적 판단 | 거짓 API·중간 거짓 주장·과장·무조건적 긍정·불가능한 제안·환경 차이·범위 확대·메모·정보 부족을 위한 사람 검토 사례를 제공합니다. 타당한 제안의 제한된 채택도 포함합니다. 의미 판단을 자동 통과시키지 않습니다. |
| 증명서 재실행 | 검사 중 입력 복구로 원래 지문을 만들어도 실패합니다. POSIX 프로세스 그룹의 백그라운드 자식과 타임아웃 잔여 실행을 정리합니다. |
| 설치 경계 | 별도 홈 설치에서 실제 호스트 등록이 호출되지 않음을 확인합니다. 실제 CLI 등록 실패와 다른 호스트용 패키지는 정상 설치로 보고하지 않습니다. 실제 CLI의 공용 경로 복사도 기존 패키지 보존 후 호스트에 맞게 복구합니다. |

공개 회귀는 `tests/test_code_contract.py`, `test_required_unittest.py`, `test_build_scenario.py`, `test_release_regressions.py`에 있습니다. 의도적으로 잘못된 코드를 넣은 평가 fixture는 실패 입력이며 배포 실행 코어가 아닙니다.

## 확인 명령

macOS 로컬 전체 회귀 363개가 111.362초에 통과했습니다. 실제 제품·평가·스크립트·시험 Python 모듈 79개의 컴파일도 통과했습니다. 의도적으로 깨뜨린 평가 fixture는 이 모듈 집계와 구분하며 독립 실패 사례로 검사합니다. 셸 문법·diff 공백·변경 문서 링크도 확인했습니다.

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests
bash -n scripts/install.sh
python3 scripts/catalog.py --check
```

설치 검사는 실제 홈을 바꾸기 전에 별도 임시 홈에서 설치·doctor·제거·보존 경로를 확인합니다. 공식 패키지 구조와 훅 진입점은 세 호스트에 대해 검사합니다. 실제 호스트의 목록·검증기 성공도 모델이 새 스킬을 채택했다는 증거와 구분합니다.

실제 macOS 설치에서도 구버전 활성 경로 세 곳을 제거하고 3.0.1 패키지로 교체했습니다. 구버전은 복구본으로 보존하며 다른 플러그인 등록은 유지했습니다. `agy 1.1.28`의 검증기는 스킬 3개와 훅 2개를 처리했습니다.

실제 CLI의 PRD·빌드·API 합성 사례 한 건은 48.767초 뒤 종료 코드 0과 `SUCCESS`를 반환했으나 `RunCommand`가 권한 부족으로 거부됐습니다. 파일 변경·제품 실행은 없었고 독립 컴파일/기능 채점은 실패했습니다. 이 시행은 실작업 성공이나 모델 품질 개선 증거가 아닙니다. 권한 우회·전역 허용 설정 변경·추가 모델 재시도는 하지 않았습니다.

## 호환성과 한계

실행 코어와 코드 작업 계약은 모델·언어 이름에 독립적입니다. 프로젝트의 실제 빌드·타입 검사·시험 명령을 연결해야 하며, 내장 시험 ID 관측은 Python unittest만 지원합니다. PRD 전체 의미·누락한 빌드 입력·시험 설계의 타당성은 자동으로 판단하지 않습니다.

실제 Gemini의 환각 감소·지침 채택률·컴파일 성공률 향상은 이번 릴리즈에서 측정하지 않았습니다. OS 샌드박스, 악성 시험의 관측 위조 방어, Windows 설치, 네트워크 파일 잠금, 모든 언어의 실행 관측, 장기 작업과 실제 기기 적합성도 보장하지 않습니다.
