# 3.0.1 검증 범위

확인일: 2026-10-16. 하네스 구현과 패키지, 설치의 무결성 검증을 실제 모델 품질과 구분하여 기록합니다.

## 구현과 직접 실패 경로

| 보호 | 확인 방법 |
| --- | --- |
| 빌드와 필수 시험 | 컴파일 실패 시 시험 실행을 차단하고, 문법이 정상이더라도 없는 API나 필드 참조는 실제 호출 단계에서 실패시킵니다. |
| 오래된 성공 | 제품 입력이나 PRD가 변경되거나 빌드를 다시 실행한 뒤에는 이전 시험 성공 기록을 무효화합니다. |
| 필수 시험 누락 | 필수 시험 ID가 실제 성공 목록에 없거나 skip으로 끝나면 실패 처리하며 조기 종료와 캐시도 함께 대조합니다. |
| 환경과 비교 | 현재 실행기와 채점 조건, 시간 제한이 다르면 비교를 차단하며 조건 일치는 비교 가능성의 근거로만 씁니다. |
| 비판적 판단 | 허위 API와 과장, 불가능한 제안을 가려내기 위한 사람 검토 사례를 제공하며 의미적 판단은 사람에게 맡깁니다. |
| 증명서 재실행 | 검사 도중 입력을 복구하여 원래 지문으로 되돌리더라도 실패 처리하며 타임아웃 잔여 프로세스를 정리합니다. |
| 설치 경계 | 별도 홈 설치에서 실제 호스트 등록이 호출되지 않음을 확인하고 구버전 복구본 보존 동작을 검증합니다. |

회귀 시험은 `tests/test_code_contract.py`, `test_required_unittest.py`, `test_build_scenario.py`, `test_release_regressions.py`에 있습니다.

## 확인 명령

macOS 로컬 전체 회귀 363개가 111.362초 만에 통과했고, 실제 제품과 평가, 스크립트 모듈 79개의 컴파일도 오류 없이 끝났습니다.

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests
bash -n scripts/install.sh
python3 scripts/catalog.py --check
```

설치 검사는 임시 홈 경로에서 설치, doctor, 제거 동작을 확인했고, 실제 macOS 환경에서도 구버전 활성 경로를 3.0.1 패키지로 교체하면서 구버전은 복구본으로 보존했습니다. `agy 1.1.28` 검증기에서는 스킬 3개와 훅 2개가 모두 정상이었습니다.

실제 CLI의 PRD, 빌드와 API 합성 사례는 종료 코드 0을 반환했으나 `RunCommand`가 권한 부족으로 거부되었고 파일 변경 없이 독립 기능 채점은 실패했습니다.

- [Python 프로세스 관리](https://docs.python.org/3/library/subprocess.html): 실제 실행과 프로세스 그룹 정리를 확인했습니다.

## 호환성과 한계

실행 코어와 코드 작업 완료 조건(`code_contract`)은 특정 모델이나 언어 이름에 독립적으로 동작합니다. 프로젝트의 실제 빌드와 시험 명령은 직접 연결해야 하며 내장 시험 ID 관측이 지원되는 것은 Python unittest뿐입니다.

실제 Gemini의 환각 감소나 지침 채택률 향상 여부는 이번 릴리즈에서 미측정 상태입니다. OS 샌드박스와 Windows 환경 설치는 보증 대상에서 제외됩니다.
