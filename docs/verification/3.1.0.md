# 3.1.0 검증 범위

확인일: 2026-11-03. 하네스 코드와 지침의 오프라인 검증 및 변경 근거 조사 내역을 기록합니다.

## 대상 모델 조사

| 모델 | 확인한 내용 | 확인 방법 |
| --- | --- | --- |
| Gemini 4 Argon | 사고 수준은 LOW, MEDIUM, HIGH이며 Google 공식 문서는 다중 파일 작업에 HIGH를 권장합니다. | 검색 결과 요약문 대조 |
| Gemini 3.8 Flash | 사고 수준은 low, medium, high이며 기본값은 medium입니다. | 검색 결과 요약문 대조 |
| Gemini 4 Carbon | 사이버 방어 협력사에 우선 제공되며 일반 공개 일정은 미정입니다. | 검색 결과 요약문 대조 |

현장 보고에 따르면 Argon은 코드베이스 동작 설명에서 오답률이 높게 나타났습니다. Gemini CLI 이슈에는 3.8 Flash가 금지 형식을 즉시 다시 쓰는 결함과 사용자 스킬을 스스로 열지 않는 현상이 보고되었습니다.

## 조사에서 채택한 지침

상시 규칙은 해야 할 일을 앞에, 금지 사항은 끝에 두는 구조로 다시 썼습니다.

조사 스킬이 검색 요약문 대신 원문 페이지를 근거로 삼도록 유도했습니다. 반복 판정은 `structure`와 `prose` 명령으로 구현했습니다.

상시 규칙과 `gtg-build`에 먼저 문제를 다시 일으켜 확인한 뒤 최소한으로 수정하도록 명시했습니다. 외부 도구 비평 연구를 바탕으로 "끝내기 전에 스스로 반박하기"를 파일 재열람, 명령 재실행, 출처 확인으로 정의했습니다.

## 구현과 직접 실패 경로

| 보호 | 확인 방법 |
| --- | --- |
| 미완성 코드 | 새로 작성한 줄의 TODO 및 본문이 비어 있는 함수를 차단합니다. |
| 대형 파일 누적 | 400줄 초과 파일과 메서드가 20개를 넘는 클래스를 차단합니다. |
| 불필요한 추상화 | 단일 구현 추상 클래스와 단순 전달 래퍼를 검토 항목으로 알립니다. |
| 기준 고정 | 시작 커밋을 `--base`로 고정하여 작업의 모든 변경을 검토합니다. |
| 문체 상투구 | 한국어와 영어 차단 규칙을 시험하고 오탐지를 방지합니다. |
| 문체 리듬 | 동일 어미 연속과 단조로운 문장 길이를 검토 항목으로 알립니다. |
| 배포 문서 | 모든 규칙과 스킬에 차단 상투구가 없는지 시험합니다. |
| 교훈 기록 | 근거가 없는 교훈을 거부하고 중복을 방지합니다. |

구조 검사 8개와 문체 검사 7개에 대해 의도적 결함을 주입하는 변이 시험을 실행해 검증기가 결함을 정상 탐지함을 확인했습니다.

## 자체 검사 결과

전체 변경에 대해 `structure`와 `prose`를 직접 실행했습니다. 주석 속 표식 인식 문제를 수정했고 복잡도 검토 기준을 radon D 등급 기준으로 정비했습니다. 식별자 집계 색인을 도입하여 2,000개 파일 규모에서 새 정의 200개 검사를 0.59초 만에 마쳤습니다.

최종 자체 검사는 차단 0건 및 검토 3건으로 끝났습니다.
