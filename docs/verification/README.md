## 경쟁 하네스와 비교

같은 사례·같은 요청·같은 채점기로 실제 실행했습니다. 64회입니다.

| 팔 | 자동 채점 | 통과 | 매번 통과 |
|---|---|---|---|
| `agy` + GTG (Gemini 3.8 Flash High) | 14 | 14 | 7/7 |
| `agy` GTG 없음 (같은 모델) | 14 | 14 | 7/7 |
| Claude Code (Sonnet 5) | 14 | 12 | 6/7 |
| Codex CLI (gpt-5.6-terra) | 14 | 13 | 6/7 |

**같은 모델에서 GTG를 켜고 끈 두 팔이 같습니다. 산출물 이점은 확인되지 않았습니다.** 원인은 모델이 16회 중 5회만 작업을 등록했기 때문입니다. 검증을 실제로 돌려야 통과하는 사례를 새로 만들어 다시 재도 4/4로 같았고, 그때는 4회 모두 등록하지 않았습니다.

자동 채점 7사례 중 6개를 네 팔 모두 매번 통과해, 이 묶음에는 변별력이 거의 없습니다. [전체 기록과 한계](../development/validation/2026-09-09-repeated-comparison/README.md)

Claude Code와 Codex는 모델이 다르므로 이 표로 제품 우열을 말할 수 없습니다.

## 고친 결함

실제로 재현한 것만 적습니다.

- 재부팅으로 PID가 재사용되면 `recover`가 영구히 거부되어 작업이 교착됐습니다. 실행 중에만 유지되는 파일 잠금으로 바꿨습니다. [기록](../development/validation/2026-09-09-reboot-recovery/README.md)
- 검사가 실행 중일 때 종료 훅이 완료를 조용히 허용했습니다. 중단된 실행이 남긴 기록도 같은 경로였습니다. [기록](../development/validation/2026-09-09-running-check-stop/README.md)
- 미실행 범위 보고가 이유 없이 비었습니다. 셸 스크립트 하나가 범위에 있으면 목록 전체가 `null`이 됐습니다. [기록](../development/validation/2026-09-09-unobservable-scope/README.md)
- 평가 도구가 작업공간에 설치된 GTG 자기 모듈을 "코드를 실행했다"로 세어 GTG에 유리하게 기울어 있었습니다.

## 아직 확인하지 못한 것

- Windows 설치
- 네트워크 파일 시스템에서의 실행 잠금
- 실제 전원 차단으로 재부팅한 기계에서의 복구. 강제 종료로만 확인했습니다.
- Go·Rust와 컴파일해서 실행하는 TypeScript의 실행 관측
- `agy` 대화형 실행. 헤드리스만 확인했습니다.
- Antigravity 서브에이전트(`agents/`). 정의 형식은 공식 문서에 있지만 실호스트에서 발견·동작을 보지 못했습니다.
- 여러 날에 걸친 장기 작업
- 토큰 사용량과 비용. 벽시계 시간만 있습니다.
