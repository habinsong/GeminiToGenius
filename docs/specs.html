기술 사양

정밀하게 설계된 하네스 아키텍처.

파이썬 표준 라이브러리 기반 로컬 실행 규격 종합 안내입니다.

종합 기술 사양서

GeminiToGenius 하네스 및 오프라인 검증 코어의 세부 규격입니다.

시스템 요구사항

지원 운영체제 macOS 12 (Monterey) 이상, Linux x86_64 / arm64, Windows 11 WSL2
필수 런타임 Python 3.10 이상 (3.11, 3.12 권장)
외부 종속 라이브러리 전무 (순수 Python 표준 라이브러리 및 셸 명령 기반)

격리 및 보안 사양

실행 격리 레벨 독립 서브프로세스 샌드박스, 작업 경로 한정 마운트
네트워크 연결 정책 오프라인 검증 기본 (외부 소켓 접속 시도시 즉각 인터럽트)
타임아웃 감시 기본 30초 단위 인터럽트 핸들러 내장

데이터 및 증명서 규격

무결성 해시 SHA-256 (256비트 암호화 해시 함수)
기록 스키마 JSON 표준 규격 (타임스탬프, 커맨드, 종료코드, 출력 버퍼)
상태 복원성 단일 명령으로 이전 검증 상태 완전 재생 지원
