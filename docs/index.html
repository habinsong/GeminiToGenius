독립 격리 실행

호스트 LLM과 물리적으로 분리된 하위 프로세스에서 명령을 실행합니다. 모델의 환각이 실행 결과를 왜곡할 수 없습니다.

호스트 지시 → 격리 하네스 → 실제 프로세스 → 종료코드 판정

사각지대 관측

실행 중 건드리지 않은 소스 파일을 추적하여, 검증되지 않은 범위를 투명하게 밝힙니다.

UNVERIFIED_SCOPE 0% (완전 포괄)

단일 아티팩트 재현성

무거운 데이터베이스 없이, 발급된 증명서 파일 하나로 누구의 컴퓨터에서나 동일한 검증 결과를 1초 만에 재현합니다.

$ python3 scripts/catalog.py --check
{"ok": true, "changed_documents": 0}
진행 흐름

단순하고 견고한 4단계 파이프라인

01

자연어 접수

슬래시 명령어 강제 없이 자연스러운 사용자 의도를 포착합니다.

02

오프라인 실행

불필요한 외부 API 호출 없이 로컬 표준 환경에서 명령을 구동합니다.

03

불변식 검사

실제 종료 코드와 파일 변경 상태의 무결성을 엄격하게 판정합니다.

04

증명 확정

결과를 타임스탬프와 해시로 묶어 변조 불가능한 증거로 남깁니다.

실행으로 입증하십시오.
