AI가 코드를 다룰 때 지키는 가장 정직한 기준.

대충 짐작해서 코드를 짜거나 확인도 안 한 채 거짓말을 하지 않도록 돕습니다. 사용자의 지시를 정확히 확인하고, 파일을 처음부터 끝까지 읽은 뒤 꼭 필요한 부분만 안전하게 수정합니다.

터미널 (macOS zsh) 1초 만에 설치하기
%git clone https://github.com/habinsong/GeminiToGenius.git && bash GeminiToGenius/scripts/install.sh

AI가 스스로 지키는 3가지 기본 약속입니다.

비전공자나 일반 사용자도 안심하고 코딩을 맡길 수 있도록 설계되었습니다.

약속 01

말씀하신 내용을 먼저 다시 확인합니다.

일을 시작하기 전에 사용자가 무엇을 요청했는지 먼저 명확하게 요약해서 말씀드립니다. 엉뚱한 방향으로 작업을 시작하지 않도록 목표를 서로 확실히 맞춥니다.

약속 02

파일을 처음부터 끝까지 꼼꼼히 읽습니다.

코드의 일부분만 대충 훑어보고 넘겨짚지 않습니다. 전체 맥락과 연관된 파일들을 빠짐없이 확인한 뒤에 꼭 고쳐야 할 부분만 조심스럽게 수정합니다.

약속 03

직접 실행해 보고 통과했을 때만 보고합니다.

확인해보지도 않고 잘 돌아간다고 거짓말하지 않습니다. 실제 화면이 잘 나오는지, 에러가 없는지 직접 테스트해 본 뒤 결과를 투명하게 말씀드립니다.

상황별로 일하는 과정을 직접 살펴보세요.

요청하신 작업 유형에 따라 AI가 어떤 순서로 문제를 해결하는지 보여드립니다.

사용자의 지시를 요약하고 목표를 정합니다.

무엇을 만들어야 하는지 명확히 확인하고 현재 폴더 상태를 점검합니다.
