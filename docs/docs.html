규칙 상세 안내

AI가 지키는 22가지 약속의 상세 해설서입니다.

안티그래비티 환경에서 AI가 안전하고 정직하게 코드를 작성하도록 돕는 핵심 엔지니어링 기준들을 알기 쉽게 풀어 설명해 드립니다.

01. 주요 규칙별 세부 내용입니다

약속 00. 복명복창
사용자가 내린 명령을 첫마디로 명확하게 요약하여 확인합니다. 불필요한 과장 광고 문구나 쓸데없는 추임새 없이, 핵심 내용만을 정중하고 친절한 한국어 문장으로 말씀드립니다.
약속 01 & 02. 사전 조사
코드를 함부로 고치기 전에 기존 코드가 어떻게 동작하고 있었는지 먼저 깊이 생각합니다. 필요한 정보는 공식 웹 문서를 직접 검색하여 확인하며, 없는 파일이나 기능을 거짓으로 지어내지 않습니다.
약속 04 & 05. 최소한의 수정
문제가 발생한 위치만 꼭 집어서 조심스럽게 고치며, 이미 잘 작동하고 있던 주변 코드는 함부로 건드리지 않습니다. 수정하기 전과 후에 어떤 부분이 바뀌었는지 꼼꼼하게 대조합니다.
약속 12. 7단계 원인 분석
에러가 발생하면 아무 코드나 무작정 수정하지 않고, 문제를 재현한 뒤 로그를 분석하여 진짜 원인을 찾아냅니다. 해결이 어려운 상황이 생기면 시도해 본 내용과 막힌 이유를 있는 그대로 투명하게 보고합니다.
약속 15. 500줄 크기 제한
파일 하나가 너무 커지면 나중에 오류를 찾고 고치기가 매우 어려워집니다. 따라서 하나의 파일이 500줄을 넘지 않도록 화면 디자인, 계산 로직, 저장 기능 등으로 깔끔하게 나누어 작성합니다.
약속 20 & 21. 정직한 보고와 금지 규율
수정한 파일과 실행한 테스트 결과, 남은 위험 요소를 정해진 표준 양식에 맞추어 보고합니다. 직접 확인해보지도 않고 성공했다고 거짓말하거나, 중요한 비밀번호 파일에 접근하는 행위는 엄격하게 금지됩니다.

02. 이전 상태로 되돌리는 복구 방법입니다

설치 시 생성된 날짜별 백업 폴더를 이용하여 언제든지 원래대로 되돌릴 수 있습니다.

터미널 복구 명령어 zsh / bash
%BACKUP_DIR="$HOME/.gemini-backup-YYYYMMDD-HHMMSS"
%mv "$BACKUP_DIR/config/agy-focus" "$HOME/.gemini/config/agy-focus"
%mv "$BACKUP_DIR/GEMINI.md" "$HOME/.gemini/GEMINI.md"
%mv "$BACKUP_DIR/config/hooks.json" "$HOME/.gemini/config/hooks.json"
%mv "$BACKUP_DIR/config/skills" "$HOME/.gemini/config/skills"
