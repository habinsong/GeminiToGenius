## 개발 기록

상세 개발 기록(로드맵, 진행 기록, 연구 출처, 파일별 원문 목록)은 저장소에 커밋하지 않는 `docs/development/` 폴더에서 관리합니다. 저장소에서 누구나 확인하실 수 있는 근거는 위 검증 문서에 모두 옮겨 두었습니다.

## 문서 작성 원칙

- 제품 문서에는 현재 동작하는 기능만 적습니다.
- 규격 문서의 필드명과 옵션명, 상태 코드는 실제 구현과 일치시킵니다.
- 검증 문서는 확인된 사실과 아직 검증하지 못한 범위를 나누어 기록하고, 추측으로 낙관하는 서술을 넣지 않습니다.
- 과장된 수식어와 상투구, 기계적인 나열을 빼고 짧고 분명한 문장으로 씁니다.
