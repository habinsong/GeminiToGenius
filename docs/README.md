## 개발 기록

상세 개발 기록(로드맵, 진행 기록, 연구 출처, 파일별 원문 목록)은 저장소에 커밋하지 않는 `docs/development/` 폴더에서 관리합니다. 공개 저장소에서 확인하실 수 있는 객관적 근거는 위 검증 문서들에 빠짐없이 옮겨 두었습니다.

## 문서 작성 원칙

- 제품 문서에는 현재 실제로 온전히 동작하는 기능만 정직하게 기술합니다.
- 규격 문서의 필드명과 옵션명, 상태 코드는 실제 구현체와 빈틈없이 일치하도록 유지합니다.
- 검증 문서는 명백히 확인된 사실과 아직 검증되지 않은 한계를 엄격히 분리하여 기록하며, 추측에 기반한 낙관적 서술을 배제합니다.
- 과장된 수식어나 진부한 상투구, 기계적인 병렬 나열을 걷어내고 간결하며 명확한 문장으로 서술합니다.
