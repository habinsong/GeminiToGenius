시작하기

한 줄의 명령어로 시작할 수 있습니다.

별도의 복잡한 의존성 설치 없이 파이썬 표준 환경에서 바로 구동됩니다.

git clone https://github.com/habinsong/GeminiToGenius

단계별 설치 과정

누구나 1분 안에 준비를 마칠 수 있습니다.

01

저장소 복제

터미널을 열고 git clone 명령으로 최신 GeminiToGenius 소스 코드를 가져옵니다.

02

디렉토리 이동

복제된 프로젝트 폴더인 GeminiToGenius 디렉토리로 이동합니다.

03

동작 검증

파이썬 단위 테스트 명령을 실행해 모든 구성요소가 정상 동작하는지 확인합니다.

빠른 실행

첫 번째 검증 실행해 보기.

터미널 쉘 - 로컬 검증 실행
$ python3 -m unittest discover tests 명령 실행
> Ran 317 tests in 84.721s OK
$ python3 scripts/catalog.py --check 목록 검사
> Catalog integrity verified (0 discrepancies) 무결성 통과
모든 테스트 오프라인 통과 완료 오류 및 결함 0건

주요 CLI 명령어

GeminiToGenius에서 제공하는 핵심 실행 스크립트 목록입니다.

명령어 레퍼런스

python3 -m unittest discover tests 프로젝트의 317개 전체 유닛 테스트 스위트를 격리 환경에서 구동합니다.
python3 scripts/catalog.py 저장소 파일 목록과 무결성 인벤토리를 최신 상태로 갱신합니다.
python3 scripts/catalog.py --check 기준 목록과 실제 파일 상태를 대조하여 임의 변경 여부를 최종 검증합니다.
  1. GeminiToGenius는 파이썬 표준 라이브러리만을 활용하므로 추가 pip 패키지 설치가 필요 없습니다.
  2. 기본 검증 작업은 오프라인 환경에서 동작하며 외부 네트워크로 소스 코드를 전송하지 않습니다.
