# 훅 상태 안내 축약 검증

실제 재개 시험의 GTG 안내 14건 중 13건은 동일했습니다. 공식 임시 메시지 계약상 이전 안내가 계속 남는다고 가정하지 않고, 매번 현재 상태를 제공하면서 중복 경로와 설명을 줄였습니다.

- `gtg/context_message.py`는 IO 없이 메시지만 구성합니다. 종료·중단·재개 판정은 기존 훅 경로를 유지합니다.
- 목표·메모의 잘림과 검사·작업 생략을 명시합니다. 전체 원문은 `status`에서 유지합니다.
- 실제와 같은 상태의 안내는 1,279 → 1,091 UTF-8 바이트로 14.7% 감소했습니다. 과금 토큰이나 모델 품질 개선 수치는 아닙니다.
- 작업 1·8·9개와 긴 메모를 비교한 네 가지 입력에서도 바이트 크기가 줄었습니다. [크기 비교](size-matrix.json).
- 신규 검사 6개 포함 전체 151개 검사가 통과했습니다. 매 호출의 파일 변경 감지, 생략된 작업의 실행·중단 보호, 다른 작업공간 후보를 확인했습니다. [검증 기록](verification.json).
- 새 구조를 요구하는 최초 검사 3개는 기존 메시지 형식에서 실패했습니다. 측정 과정의 임시 경로 오류는 실제 경로 정규화 후 해소했습니다.

[실제 주입 기록](native-injection-audit.json), [같은 상태 비교](message-comparison.json), [검사 로그](tests.log)를 보존했습니다. 추가 모델 호출은 없습니다. 새 메시지 표현의 실호스트 행동·토큰 비용·품질 효과는 미검증입니다.
