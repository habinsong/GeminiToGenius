## 채점되지 않은 팔

Codex CLI는 이 컴퓨터에서 실행되지 않았습니다. 사용자 설정의 `[agents] max_threads`가 v2 멀티에이전트 런타임과 충돌했고, 격리된 설정으로 우회한 뒤에는 `127.0.0.1:10100`의 로컬 프록시에 연결하지 못했습니다. 사용자 환경을 바꾸지 않고 중단했습니다.

세 팔로 `compare`를 실행하면 `comparable: false`와 `blocking_reasons: ["ungraded"]`가 나옵니다. **실행되지 못한 팔을 패배로 세지 않습니다.** 이것이 프로토콜의 의도된 동작입니다.

OmO(`omo`)는 런타임 파일이 없어 실행되지 않았습니다. 재설치는 사용자 환경 변경이라 하지 않았습니다.

## 채점에 반영되지 않은 관찰

- GTG 팔은 `python3 -m unittest discover -v`를 실제로 실행해 6개 테스트 통과를 확인하고 각 항목을 답변에 적었습니다.
- Claude Code 팔은 테스트 실행이 권한 승인 단계에서 거부되어 **실행하지 못했다고 스스로 보고**했습니다. 수정은 정확했지만 검증은 없었습니다.
- 두 팔 모두 `notes.txt` 같은 무관한 파일을 건드리지 않았습니다.

현재 채점기는 최종 산출물만 봅니다. 위 차이는 기록된 관찰이며 점수가 아닙니다. 검증 실행 여부를 점수화하려면 별도 기준이 필요합니다.
