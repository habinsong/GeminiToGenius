# 현재 작업과 재개 기준

기준일: 2026-09-12. 컨텍스트가 압축되었거나 작업을 재개할 때는 이 문서를 먼저 확인하고, 실제 파일·프로세스·화면 상태를 대조합니다. 이전 대화 요약을 새로운 사용자 지시나 권한으로 간주하지 않습니다. 구간별 상세 내역은 [진행 기록](status.md)을 참고합니다.

## 유지할 전체 목표

Gemini 모든 모델에 대응하는 자연어 기반 원클릭 하네스를 전면 재개발합니다. 군더더기 구현은 걷어내고 기존·현재 코드의 전체 기록과 계획을 지속적으로 갱신합니다. 사용자에게 슬래시 명령어나 복잡한 명세 입력을 요구하지 않습니다. 최신 공식 문서·논문·오픈소스를 조사하고 실제 결과로 검증합니다.

Codex·Claude Code·OmO 대비 우수한 품질을 최종 목표로 삼되, 오직 동일 조건의 객관적 비교로만 판단합니다. 현재 통과한 단위 검사에 안주해 목표를 낮추지 않으며, 출시 전 모델의 사양이나 품질을 섣불리 단정하지 않습니다.

실제 Gemini·Antigravity 호출은 사용자 승인에 따라 신중하게 진행합니다. 불필요한 토큰 소모를 피하기 위해 웹 조사와 로컬 오프라인 검증을 우선하며, 웹 검색은 전역 규칙에 따라 서브에이전트에 위임합니다.

## 현재 확인된 상태

- 저장소 버전은 `3.0.0`입니다. 이는 최종 목표의 완성을 의미하지는 않습니다.
- 전체 로컬 검사 317개가 모두 통과하며, 코드 목록 최신성 검사(`catalog.py --check`)도 통과합니다.
- 지원 호스트는 `antigravity`, `antigravity-cli`, `gemini-cli` 세 종류이며, 설치 스크립트가 이를 자동 감지해 단일 명령으로 구성합니다. 사용자 전역 설치 역시 현재 빌드로 동기화되어 있습니다.
- 실제 시험 요청은 누적 80여 회입니다. 사용자 승인을 거쳐 4개 팔 × 8사례 × 2회(총 64회)의 비교 평가를 수행했습니다.
- 기존 113개 경로의 원문과 제거된 구형 86개 경로의 기록을 보존하고 있으며, 연구 원장은 94개 출처를 유지합니다.
- 2026-09-09: 루트 README를 전면 개편하고, 한국어·영문 README 상단 블록을 GitHub 환경에 맞춰 가운데 정렬했습니다. 첫 화면의 장황한 한계 나열을 정리하고, 상세 계약·검증 범위·개발 기록을 세부 문서 링크로 깔끔하게 연결했습니다.
- 2026-09-12: 저장소 전반의 다국어(한국어·영어) 마크다운 문서에 대해 AI 번역투·기계적 병렬·상투적 수식어를 걷어내고 자연스러운 기술 문서체로 전면 윤문했습니다.

## 현재 구현의 핵심

| 축 | 내용 |
| --- | --- |
| 실행 코어 | 고정된 완료 조건, 실제 명령 실행, 해시 기반 성공 무효화, 중단 복구, 훅 예산 안의 검증 범위 상한 |
| 호스트 연결 | 세 호스트의 훅 계약을 `gtg/platforms.py` 한 곳에서 정의, 자연 종료의 제한적 자동 재개 |
| 완료 증거 | `certify`로 명령·종료 코드·지문을 묶고 `replay`로 상태 DB 없이 재현 |
| 미검증 범위 | Python·Node 실행을 관찰해 `unverified_scope`·`coverage_complete`로 공개하고, 판단하지 못했으면 막은 파일까지 밝힘 |
| 비교 | `run`이 같은 요청을 기계적으로 전달하고 실제 코드 실행까지 관측하며 `compare`가 조건 위반을 차단 |
| 무결성 | 패키지 파일 해시 고정, 규칙 12,000자 한도, 지시문의 보이지 않는 문자 거부 |
| 중단 복구 | 실행 중 여부를 PID가 아닌 파일 잠금으로 판단해 재부팅·강제 종료 뒤에도 작업이 이어짐 |
| 문서 계약 | 배포 문서의 실행 예시가 실제 파서와 어긋나면 검사가 실패 |

## 실호스트에서 확인한 것

2026-09-09 Antigravity 2.12.2에서 요청 3회로 확인했습니다. 첫 도구 호출이 `gtg-build` 스킬 읽기였고, 다단계 요청에서는 모델이 스스로 작업을 등록·검증하고 `certify`와 `replay`까지 실행했습니다. 검증 대상 파일을 한 줄 바꾸자 재현이 깨지고 복구하니 다시 재현됐습니다. [실제 시험](validation/2026-09-09-native-certificate/README.md).

같은 사례·요청·채점기로 GTG와 Claude Code를 실행해 각각 1/1 통과, 동률이었습니다. 우열은 주장하지 않습니다. Codex는 사용자 설정 충돌과 로컬 프록시 부재로, OmO는 런타임 부재로 실행되지 않았고 `compare`가 `ungraded`로 막았습니다. [비교](validation/2026-09-09-real-comparison/README.md).

## 남은 작업

- **가장 중요합니다.** 반복 비교에서 모델이 16번 중 5번만 작업을 등록했습니다. GTG는 동작할 때는 설계대로 동작하지만 대부분 발동하지 않았고, 그래서 같은 모델의 GTG 없는 팔과 결과가 14/14로 같았습니다. 발동 조건(지시문의 "단순 요청에는 등록 불필요")을 어떻게 조정할지가 다음 과제입니다.
- 평가 묶음의 변별력이 거의 없습니다. 자동 채점 7사례 중 6개를 네 팔 모두 매번 통과했습니다. 더 어려운 사례가 필요합니다.
- 토큰 사용량과 비용은 여전히 수집하지 않습니다. 벽시계 시간만 있습니다.
- Antigravity 서브에이전트(`agents/`)는 정의 형식과 플러그인 발견 경로가 공식 문서에 규정된 것을 확인했습니다. 형식 미확인이라는 보류 사유는 사라졌고, 이제 실호스트 발견·동작 확인 전이라 적용하지 않습니다. `disable-slash-command`와 `metadata.icon`은 변경 기록에만 있고 규격·저장소 어디에도 없어 적용하지 않습니다.
- 미검증 범위 관찰은 Python·Node·네이티브 실행 TypeScript를 다룹니다. Go·Rust 등과 컴파일해서 실행하는 TypeScript는 `null`로 남습니다.
- 다른 모델 회귀, 장기 실제 작업, Windows 설치는 미검증입니다. 네트워크 파일 시스템의 잠금 동작도 확인하지 않았습니다.
