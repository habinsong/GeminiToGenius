검증 절차

동작 증거를 남기는 4단계 프로세스.

환경 격리부터 실행, 상태 비교, 증명서 발급까지 일관된 흐름으로 진행됩니다.

시작 가이드 사양 확인

단계별 실행 흐름

타협 없는 무결성 검증 기준.

01

환경 격리

외부 네트워크와 호스트 주요 경로가 차단된 독립 서브프로세스 공간을 마련합니다.

02

실제 구동

실제 테스트 대상 코드를 온전히 실행하여 표준 출력과 종료 코드를 수집합니다.

03

상태 대조

실행 전후의 파일 해시와 디렉토리 무결성을 비교하여 예상치 못한 변경을 탐지합니다.

04

증명서 발급

모든 검증 결과를 재현 가능한 JSON 사양서로 봉인하여 완결된 증거를 남깁니다.

검증 파이프라인 사양

각 단계에서 보장되는 불변 조건입니다.

불변식 기준

종료 코드 판정 Exit Code 0인 경우에만 정상 판정 (비정상 종료 시 즉시 실패 처리)
해시 무결성 검증 전후 기준 파일 목록 불일치 발생 시 즉각 경고 및 중단
기록 보존 검증 이력과 증명서는 로컬 디렉토리에 버전별로 안전하게 보존
