재현 메커니즘

기록된 증거로 오차 없이 검증합니다.

01

증명서 생성

코드 실행 시점의 입력 데이터, 파일 상태, 해시값을 JSON 기록 파일로 캡슐화합니다.

02

사양서 검증

다른 머신에서 기록 파일을 읽어 호환되는 파이썬 런타임과 환경 무결성을 대조합니다.

03

즉각 재생

외부 네트워크 통신 없이 0.02초 내에 동일한 테스트 결과를 완전히 재현합니다.

재현 사양서 규격

GeminiToGenius 재현 엔진의 세부 기술 데이터입니다.

기록 규격

해시 알고리즘 SHA-256 (실행 대상 파일 및 출력 데이터 무결성 검증)
기록 데이터 형식 표준 JSON (입력 명령, 반환 코드, 표준 출력, 표준 오류, 실행 시각)
호환성 macOS, Linux, Windows 간 교차 검증 지원
