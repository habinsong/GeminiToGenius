원천 차단 기반 격리 원칙.

테스트 대상 코드가 호스트 시스템의 중요 자원에 영향을 주지 못하도록 설계되었습니다.

01

네트워크 차단

소켓 바인딩 및 외부 HTTP 요청을 원천 차단하여 정보 유출 가능성을 봉쇄합니다.

02

디렉토리 제한

테스트 전용 임시 디렉토리 외 시스템 주요 경로에 대한 쓰기 권한을 제한합니다.

03

자동 자원 정리

검증 종료 즉시 생성된 임시 프로세스와 파생 파일들을 남김없이 소거합니다.

통제 범위 상세

명확하게 정의된 접근 권한.

차단 대상

외부 통신 및 호스트 자원

외부 인터넷 연결, SSH 키 파일 접근, 상위 시스템 루트 디렉토리 수정, 프로세스 권한 상승 시도를 즉각 차단합니다.

허용 대상

검증 대상 순수 로직

표준 라이브러리 연산, 로컬 파일 읽기/쓰기(지정 경로 내), 표준 출력 및 오류 출력 생성을 완벽히 지원합니다.

샌드박스 기술 규격

GeminiToGenius 로컬 격리 시스템의 상세 스펙입니다.

보안 정책 규격

네트워크 소켓 정책 오프라인 검증 기본 (네트워크 시도 시 소켓 예외 발생 및 기록)
환경 변수 분리 호스트 API 키 및 민감 환경 변수 기본 격리 후 정제된 변수만 전달
정리 메커니즘 종료 시그널 수신 즉시 프로세스 트리 종료 및 임시 공간 정리
