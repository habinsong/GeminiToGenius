자연어 지시 수용

슬래시 명령 없이 직관적인 대화로.

특정 명령어 문법을 암기할 필요 없이 일상적인 문장으로 검증을 지시할 수 있습니다.

사용 가이드 해석 사양 보기
자연어 해석 및 실행 준비
입력 "방금 수정한 모듈 테스트 돌리고 확인해줘" 자연어 수신
해석 최근 변경 파일 감지 및 실행 파이프라인 매핑 매핑 성공

해석 파이프라인

의도를 정확히 파악하여 안전하게 실행합니다.

01

문맥 파악

현재 프로젝트의 변경 이력과 직전 대화 기록을 바탕으로 사용자의 요청 의도를 분석합니다.

02

실행 경로 수립

안전한 격리 환경에서 구동할 정확한 스크립트와 파라미터 조합을 자동으로 구성합니다.

03

결과 브리핑

복잡한 로우 로그 대신 핵심 검증 결과와 변경 내역을 사람이 읽기 편한 요약문으로 전달합니다.

자연어 인터페이스 규격

GeminiToGenius 대화형 인터페이스 상세 사양입니다.

인터페이스 사양

명령어 형식 슬래시(/) 접두사 없는 순수 자연어 문장 지원
문맥 참조 범위 현재 작업 디렉토리의 git 상태, 최근 수정 파일, 직전 오류 로그
