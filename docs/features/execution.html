실행 기반 테스트

코드, 실행해서 검증합니다.

눈으로 훑는 리뷰를 넘어, 실제 프로세스를 띄워 정상 구동 여부를 판정합니다.

작동 방식

엄격한 3단계 파이프라인.

모든 실행은 시작부터 종료까지 독립된 하위 프로세스에서 통제됩니다.

01

환경 격리

외부 통신과 시스템 주요 영역을 차단한 임시 작업 공간을 할당합니다.

02

실제 구동

격리된 프로세스 내에서 대상 명령과 테스트 코드를 직접 실행합니다.

03

결과 판정

종료 코드 0 여부와 입출력 무결성을 대조하여 최종 합격을 확정합니다.

정밀 검증 항목

동작의 사소한 부분까지 기록합니다.

항목 01

프로세스 종료 코드

비정상 종료나 시스템 시그널 인터럽트 발생 시 즉시 감지하여 원인 로그를 남깁니다.

항목 02

표준 입출력 무결성

표준 출력(stdout)과 에러 출력(stderr)을 실시간으로 분리 기록하여 예상 출력과 대조합니다.

항목 03

타임아웃 감시

무한 루프나 블로킹 호출이 발생할 경우 지정된 한도 시간 내에 프로세스를 안전하게 정리합니다.

항목 04

파일 변경 추적

실행 전후의 파일 해시를 비교하여 의도하지 않은 파일 변조를 사전에 차단합니다.

실행 엔진 사양

GeminiToGenius 로컬 검증 엔진의 상세 기술 규격입니다.

런타임 요구사항

운영체제 macOS 12 이상, Linux (Ubuntu 20.04+, Debian 11+), Windows 11 WSL2
파이썬 버전 Python 3.10 이상 (표준 라이브러리 기반 구동)
외부 종속성 없음 (추가 패키지 설치 없이 즉시 실행 가능)

프로세스 격리 규격

격리 방식 독립 서브프로세스 파이프라인 및 파일시스템 마운트 격리
네트워크 정책 소켓 연결 원천 차단 (오프라인 모드 기본 활성화)
타임아웃 기본값 단일 명령 검증 시 기본 30초 (설정 파일로 조정 가능)
