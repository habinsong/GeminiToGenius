# 종료 훅 연결 시험

이 폴더는 실제 호스트의 종료·재개 연결만 확인하는 격리된 시험입니다. 코드 개선이나 모델 성능 평가는 아닙니다. 제공한 레코드 처리 코드와 검사 6개는 사전 검증됐습니다.

1. `.gtg/task.json`을 읽고 현재 프로젝트의 `.agents/plugins/geminitogenius/run.py`로 작업을 등록합니다. `start --spec .gtg/task.json --workspace . --platform antigravity --session` 뒤에는 초기 GTG 메타데이터에 실제로 주입된 세션 ID를 사용합니다. ID를 추측하지 않습니다.
2. 첫 응답에서는 등록만 수행합니다. 검사는 실행하지 않고 `작업을 등록했습니다. 종료 훅의 재개를 기다립니다.`라고 응답을 끝냅니다. 전체 작업이 완료됐다는 뜻은 아닙니다. 자연 종료 후 훅이 미검증 상태를 발견하는 경로를 시험하기 위한 순서입니다.
3. 호스트가 GTG 미검증 상태를 주입해 재개하면, 같은 작업 ID로 `verify`를 실행합니다. 등록된 회귀 검사 결과와 최종 `verified`를 확인해 보고합니다.

이 시험에서는 `pause`, `resume`, 별도 반복 실행을 사용하지 않습니다. 코드·검사·명세·플러그인·전역 설정을 변경하지 않습니다. 필요한 로컬 조회·등록·검증만 수행하며 하위 에이전트나 외부 요청은 필요하지 않습니다. 재개되지 않으면 후속 요청을 스스로 만들지 않습니다.

관찰자는 자연 종료와 실제 재개 메시지, 영속 상태의 재개 횟수, 실제 검사 실행 결과를 대조합니다. 첫 응답부터 검사를 실행하면 종료 후 재개가 확인된 것으로 집계하지 않습니다.
