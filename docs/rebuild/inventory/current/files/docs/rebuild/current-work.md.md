## 유지할 전체 목표

Gemini 전 모델에 맞는 자연어 원클릭 하네스의 전면 재개발입니다. 기존의 불필요한 구현은 제거하고 기존·현재 코드 전체 기록과 계획을 계속 갱신합니다. 사용자에게 슬래시 명령·정교한 명세를 요구하지 않습니다. 최신 공식 자료·논문·오픈소스를 조사하고 실제 결과로 검증합니다.

Codex·Claude Code·OmO보다 나은 결과가 최종 목표이며 같은 조건의 비교로만 판단합니다. 현재 통과한 검사에 맞춰 목표를 축소하지 않습니다. 출시 전 모델의 호환성·품질을 미리 단정하지 않습니다.

실제 Gemini·Antigravity 사용은 사용자 지시에 따릅니다. 직전 지시는 토큰 비용 때문에 사용하지 말라는 것이었으므로 웹 조사와 로컬 검증으로 진행합니다. 웹 검색은 전역 규칙에 따라 서브에이전트에 위임합니다.
