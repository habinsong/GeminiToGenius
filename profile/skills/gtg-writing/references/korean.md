# 한국어

한국어 AI 문체는 몇 가지 버릇이 겹쳐서 생깁니다. 하나만 있으면 사람 글에도 흔하지만 여러 개가 한 문단에 몰리면 바로 티가 납니다. 표현을 하나씩 바꾸기보다 문장 구조를 다시 짜세요.

## 끊어진 리듬

AI가 쓴 한국어는 짧은 문장을 줄지어 세우는 경우가 많습니다. 사람은 이어지는 생각을 연결어미로 묶어 길게 쓰다가, 강조할 때만 짧게 끊습니다.

- 고치기 전: `설치가 끝났습니다. 설정 파일을 엽니다. 값을 바꿉니다. 저장합니다.`
- 고친 뒤: `설치가 끝나면 설정 파일을 열어 값을 바꾸고 저장합니다.`

같은 어미가 다섯 문장 넘게 이어지면(`~합니다. ~합니다. ~합니다.`) 앞뒤 문장을 이어 보세요. 어미만 억지로 바꾸는 것보다 문장을 잇는 편이 자연스럽습니다. 반대로 쉼표로 절을 네다섯 개 이어 붙인 영어식 긴 문장도 읽기 어려우니, 그럴 때는 마침표로 나눕니다.

## 바로 지울 상투구

| 표현 | 이렇게 |
| --- | --- |
| `결론적으로`, `요약하자면`, `종합하면` | 지우고 결론을 바로 씁니다 |
| `시사하는 바가 크다`, `주목할 만하다`, `간과할 수 없다` | 무엇이 왜 중요한지 사실로 씁니다 |
| `~라고 할 수 있습니다`, `~라고 볼 수 있습니다` | 근거가 있으면 단정하고, 없으면 무엇이 불확실한지 씁니다 |
| `알아보겠습니다`, `살펴보겠습니다`, `도움이 되셨으면 좋겠습니다` | 문서에서는 지우고 본론부터 씁니다 |
| `새로운 지평`, `패러다임 전환`, `게임 체인저` | 실제로 바뀐 것을 씁니다 |
| `~되어지다`, `~되어진` | `~되다`나 능동문으로 씁니다 |

## 몰릴 때만 고칠 표현

아래 표현은 사람도 자주 씁니다. 사람 글과 AI 글을 비교한 공개 측정에서 `~에 대해`, `~를 통해`, `~을 위해`는 오히려 사람 글에 더 많았습니다. 그러니 한 번 나왔다고 지우지 말고, 한 문단에 세 번 넘게 몰릴 때 손봅니다.

- 번역투 연결: `~에 있어서`는 `~에서`로, `~와 관련하여`는 `~에`로, `~에 기반하여`는 `~로`로 줄입니다. `AI에 의해 생성된`은 `AI가 만든`으로, `강한 경쟁력을 가지고 있다`는 `경쟁력이 강하다`로 씁니다.
- 문장 첫 접속사: `또한`, `아울러`, `나아가`, `따라서`, `즉`이 매 문장 앞에 붙으면 절반 넘게 덜어냅니다. 앞뒤 문장이 이미 이어지면 접속사가 없어도 됩니다.
- 가능형 반복: `~할 수 있습니다`가 네 번 넘게 이어지면, 실제로 하는 일은 `~합니다`로 쓰고 가능성은 조건을 밝힙니다. 의학·법률·정책 글에서는 가능형이 뜻 자체이므로 그대로 둡니다.
- 분열문: `중요한 것은 X입니다`보다 `X가 중요합니다`가 읽기 쉽습니다.
- 꾸밈말: `혁신적`, `획기적`, `압도적`, `강력한`, `원활한`은 수치나 사실로 바꿀 수 있는지 봅니다.
- 과장: `완벽하게`, `모든 경우에서`, `문제없이`, `무결점`은 확인한 범위를 쓰거나 표현을 낮춥니다.

## 구조 버릇

- 변환 공식(`X에서 Y로`, `X를 넘어 Y로`)을 문단마다 쓰지 않습니다. 문서 하나에 한 번이면 충분합니다.
- `~할 때입니다`, `~할 시점입니다`로 글을 맺지 않습니다.
- 앞 문장에 가리킬 대상이 없는데 `이는`, `그것은`으로 문장을 열지 않습니다. 대상이 하나면 생략하고, 여럿이면 명사를 다시 씁니다.
- 개념어마다 따옴표나 굵은 글씨를 씌우지 않습니다. 정말 놓치면 안 되는 한 곳에만 씁니다.
- 근거가 셋이 아닌데 셋으로 맞추지 않습니다. 이어지는 이야기는 목록이 아니라 문단으로 씁니다.
- 한 문서 안에서 `~합니다`체와 `~한다`체를 섞지 않습니다.
