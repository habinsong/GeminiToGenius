# 논문 문장 고친 예

모두 이 저장소에서 새로 쓴 예문입니다. 고친 뒤 문장에 원문에 없던 수치나 사실이 들어가지 않았는지도 함께 보세요. 대괄호는 원문에서 가져와 채울 자리입니다.

## 명사 쌓기

- 고치기 전: `본 연구에서는 대규모 언어 모델의 한국어 생성 능력 평가를 위한 벤치마크 구축을 수행하였다.`
- 고친 뒤: `본 연구는 대규모 언어 모델이 한국어를 얼마나 잘 생성하는지 평가하는 벤치마크를 만들었다.`

`평가를 위한 구축을 수행하였다`처럼 명사 셋을 동사 하나에 매달면 무엇을 했는지가 문장 끝까지 미뤄집니다. 실제로 한 일(`만들었다`)을 동사로 쓰고 꾸밈은 그 앞에 둡니다.

## 사람이 한 일의 피동

- 고치기 전: `이 지표는 Kim 외(2024)에 의해 제안되었으며 이후 여러 연구에 의해 활용되었다.`
- 고친 뒤: `이 지표는 Kim 외(2024)가 제안했고 이후 여러 연구가 썼다.`

`X에 의해 매개된다`처럼 변수 사이의 관계를 말하는 피동은 그대로 둡니다. 능동으로 바꾸면 뜻이 달라집니다.

## 겹친 완곡

- 고치기 전: `이러한 결과는 모델의 크기가 성능에 영향을 미친다는 것을 시사한다고 볼 수 있을 것이다.`
- 고친 뒤: `이 결과는 모델 크기가 성능에 영향을 준다는 점을 시사한다.`

완곡을 하나만 남겼습니다. 표본이 작아서 단정하기 어렵다면 그 이유를 따로 한 문장으로 씁니다(`다만 표본이 [n]개라 일반화하기는 어렵다.`).

## 대구

- 고치기 전: `문제는 데이터의 양이 아니라 질이며, 모델의 크기가 아니라 학습 방식이다.`
- 고친 뒤: `데이터는 양보다 질이 중요했다. 모델 크기보다 학습 방식의 영향도 더 컸다.`

`A가 아니라 B`를 `A보다 B`로 바꾸고 두 번째 대구는 다른 문장으로 떼어 대칭을 깼습니다. 대구가 결과를 정확히 요약한다면 하나는 남겨도 됩니다.

## 문장 첫 접속사와 쉼표

- 고치기 전: `또한, 본 연구는 세 가지 데이터셋을 사용하였다. 따라서, 결과의 일반화 가능성이 높다고 할 수 있다.`
- 고친 뒤: `본 연구는 데이터셋 세 개로 실험했으므로 결과를 한 데이터셋에서 얻은 경우보다 넓게 적용할 수 있다.`

`또한,`과 `따라서,`의 쉼표를 지우고 두 문장의 인과를 연결어미(`~했으므로`)로 이었습니다. `일반화 가능성이 높다`는 무엇에 비해 높은지가 빠져 있어 비교 기준을 넣었습니다.

## 용어

- 고치기 전: `Large Language Model(LLM)의 Hallucination은 ... 이러한 Hallucination 현상을 줄이기 위해 RAG(Retrieval-Augmented Generation)를 ...`
- 고친 뒤: `대규모 언어 모델(large language model, LLM)의 환각(hallucination)은 ... 환각을 줄이려고 검색 증강 생성(retrieval-augmented generation, RAG)을 ...`

병기는 처음 한 번만 합니다. 투고 규정이 영문 용어를 그대로 쓰라고 하면 `hallucination`으로 통일하되, 조사는 한글로 읽은 받침에 맞춥니다(`LLM은`, `RAG를`). 영어 어근에 `-하다`를 바로 붙인 `fine-tuning했다`는 `fine-tuning을 했다`로 씁니다.

## 수치

- 고치기 전: `제안 모델의 정확도는 기존 모델 대비 2% 향상된 72%를 기록하였다.` (기존 모델은 70%)
- 고친 뒤: `제안 모델의 정확도는 72%로 기존 모델(70%)보다 2%p 높았다.`

비율끼리의 차이는 %p입니다. 상대 변화로 쓰려면 `약 2.9% 높았다`입니다. `기록하였다`, `달성하였다`는 수치를 그냥 쓰면 필요 없습니다.

## 앞일과 결론

- 고치기 전: `향후 연구에서는 더 큰 모델에 대한 실험이 수행될 것이다. 본 연구는 한국어 자연어 처리 분야에 새로운 지평을 열었다는 점에서 의의가 크다.`
- 고친 뒤: `더 큰 모델로 실험하는 일은 후속 연구로 남긴다. 본 연구의 벤치마크는 [기존 자료에 없던 과제]를 다룬다.`

`~될 것이다`를 계획을 밝히는 말로 바꿨고, 의의를 부풀리는 문장은 무엇이 새로웠는지 적는 문장으로 바꿨습니다. 무엇이 새로운지가 원문에 없다면 지어내지 말고 그 문장을 지웁니다.

## 그대로 두는 것

AI 문체처럼 보여도 논문에서는 관례인 표현이 있습니다.

| 표현 | 판단 |
| --- | --- |
| `본 연구는`, `본 논문은` | 국문 논문의 관례입니다. 가벼운 실험 노트라면 `이 연구는`이 자연스럽습니다 |
| `~로 알려져 있다`, `X에 의해 매개된다` | 학술 정형 피동입니다 |
| `~을 시사한다`, `~라고 볼 수 있다` 한두 번 | 근거의 수준을 밝히는 관례적 완곡입니다 |
| 기여를 `첫째`, `둘째`로 나열 | 서론의 기여 목록에서는 관례입니다 |
| 해라체만 이어지는 본문 | 논문의 기본입니다. 해요체를 섞지 않습니다 |
| `데이터 기반 의사결정` 같은 굳은 합성어 | 하나의 용어라 풀지 않습니다 |
| 직접 인용 | 남의 말이라 규칙과 다르더라도 그대로 둡니다 |
