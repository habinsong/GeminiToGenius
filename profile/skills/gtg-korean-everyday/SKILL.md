# 일상 대화와 글

일상 글은 받는 사람이 한 번 읽고 바로 알아듣게 쓰면 됩니다. AI가 쓴 일상 글은 대개 너무 공손하고 너무 길며, 상대가 한 말과 상관없는 공감부터 늘어놓습니다. 공통 기준은 `gtg-writing`의 [한국어](../gtg-writing/references/korean.md)에 있고, 여기서는 일상 글에서 달라지는 점만 다룹니다.

## 먼저 정할 것

누구에게, 어디로 보내는 글인지 먼저 정합니다. 높임 등급은 문장 기술이 아니라 관계가 정하기 때문입니다. 다듬는 일이라면 원문의 등급을 그대로 둡니다.

| 상대 | 등급 | 예 |
| --- | --- | --- |
| 친구, 동생, 가까운 동기 | 반말 | `내일 볼래?` |
| 동료, 처음 보는 또래, 단골 가게 | 해요체 | `내일 볼까요?` |
| 고객, 윗사람, 공식 메일 | 합쇼체에 해요체를 섞어서 | `내일 뵙겠습니다. 장소는 문자로 보내 드릴게요.` |

## 이렇게 씁니다

첫 문장에 답을 씁니다. 물어본 것에 바로 답하고 이유나 덧붙일 말은 그 뒤에 둡니다. `좋은 질문이에요`, `알아볼게요`로 시작하지 않습니다.

말하듯 씁니다. 해요체로만 이어지면 `~요. ~요. ~요.`가 되풀이되는데, 사람은 말하면서 `~거든요`, `~더라고요`, `~잖아요`, `~네요`, `~죠`를 저절로 섞습니다. 어미를 일부러 바꾸기보다 실제로 말할 때처럼 이유를 대고(`~거든요`), 겪은 일을 전하고(`~더라고요`), 아는 사실을 짚으면(`~잖아요`) 자연스럽게 섞입니다. 공식 메일도 합쇼체만 열 문장 넘게 이어지면 딱딱하니, 가벼운 문장은 `~요`로 풀어도 됩니다.

상대가 한 말을 받아서 답합니다. `정말 힘드셨겠어요`, `충분히 이해합니다`, `그런 마음이 드는 게 당연해요` 같은 공감 문구는 아무 이야기에나 붙일 수 있어서 오히려 듣지 않은 것처럼 들립니다. 상대가 말한 구체적인 사정을 한 번 짚어 주는 편이 낫습니다.

높일 사람만 높입니다. `커피 나오셨습니다`, `품절이십니다`, `말씀이 계시겠습니다`는 `커피 나왔습니다`, `품절입니다`, `말씀이 있겠습니다`로 씁니다. `추천드립니다`, `안내드립니다`, `전달드리도록 하겠습니다`처럼 `드리다`를 겹겹이 붙인 말도 `추천해요`, `알려 드려요`, `보내 드릴게요`면 충분합니다.

개인 메시지에 안내문 말투를 쓰지 않습니다. `참고하시기 바랍니다`, `양해 부탁드립니다`, `금일`, `상기 내용`은 공문에 어울리는 말입니다.

짧은 글은 짧게 씁니다. 카톡 답장에 제목이나 목록, 굵은 글씨를 넣지 않고 세 문단으로 늘리지도 않습니다. 느낌표와 이모지는 상대가 쓰는 만큼만 씁니다. 말로 다 하지 않아도 되는 것은 남겨 두세요. 사람끼리는 서로 아는 것을 다시 설명하지 않습니다.

## 고치는 순서

1. 받는 사람과 보내는 곳(카톡, 메일, 블로그)을 정하고 높임 등급을 고릅니다.
2. 답이나 용건을 첫 문장으로 옮깁니다.
3. 공감 상투구, 사물 존대, 겹친 `드리다`, 안내문 말투, 번역투를 걷어냅니다. 고친 예는 [고친 예](references/everyday.md)에 있습니다.
4. 검사합니다. 카톡 답장이나 메일 초안처럼 파일이 아닌 글은 표준 입력으로 넘기면 됩니다.

   ```bash
   python3 "$GTG_RUNNER" prose --register everyday - <<'EOF'
   (보낼 글)
   EOF
   ```

   다듬는 일이면 원문을 따로 복사해 두고 `--original 원문파일`을 붙입니다. 보내려던 날짜·금액·번호가 바뀌었는지 도구가 확인합니다.

5. 소리 내어 읽어 봅니다. 실제로 그 사람에게 그 말을 하는 장면이 어색하면 다시 고칩니다.

`everyday` 갈래는 구어에서 자연스러운 도치와 짧은 문장을 문제 삼지 않고, 같은 말로 이어 시작하는 문장도 알리기만 하며 점수는 내리지 않습니다. 대신 일상 글인데 거의 모든 문장이 `~니다`로 끝나거나, `~요`로만 끝나고 말할 때 쓰는 어미가 하나도 없을 때 알립니다. `정말 힘들었겠다`, `충분히 잘하고 있어` 같은 공감 문구는 두 번 이상 나오면 알립니다. 초안에 흔한 맞춤법 오류(`되요`, `할께`, `몇일`)도 찾아 주지만 AI 문체가 아니라서 점수에는 넣지 않습니다. 결과의 `score`는 찾은 신호를 분량으로 나눈 점수라서 짧은 메시지에서는 신호 하나로도 크게 움직입니다. 일상 글은 사람이 쓴 정답 자료가 없어서 이 갈래의 규칙과 점수를 시험 문장으로만 확인했습니다.
