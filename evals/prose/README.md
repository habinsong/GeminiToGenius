# 문체 점수 실측 절차 (모델 출력)

`prose` 점수가 Gemini가 실제로 쓴 한국어에서 어떻게 나오는지 재는 절차입니다. 3.3.0까지 이 저장소에 **Gemini 출력으로 잰 값은 없습니다.** 점수를 맞춘 자료는 KatFish(사람 글과 2024년 LLM 글)뿐이고, 개발 환경에 Gemini CLI와 API 키가 없어서 이 절차를 직접 돌리지 못했습니다. 아래 도구는 사용자가 한 번 모은 출력을 오프라인으로 재는 용도입니다.

## 쿼터

프롬프트는 26개이고 윤문 6개가 들어 있습니다. 조건 하나(예: GTG 없음, GTG 있음)마다 26번 호출하면 됩니다. 점수를 재는 일은 모델을 부르지 않으므로 몇 번을 다시 재도 쿼터를 쓰지 않습니다. 같은 조건을 여러 번 반복하는 것은 권하지 않습니다. 결과가 마음에 들 때까지 다시 돌리면 측정이 아니라 고르기가 됩니다.

## 절차

1. 프롬프트를 파일로 꺼냅니다. 모델은 부르지 않습니다.

   ```bash
   python3 scripts/prose_calibration.py --export-prompts /tmp/prose-prompts
   ```

2. `/tmp/prose-prompts/<id>.prompt.txt`의 내용을 조건마다 한 번씩 모델에 보내고, 응답 본문만 `<폴더>/<id>.md`로 저장합니다. 인사말이나 도구 호출 기록이 섞이면 점수가 달라지니 본문만 남깁니다. Antigravity CLI는 헤드리스 모드(`agy -p`)에서 `--add-dir`로 작업공간을 지정해야 훅이 동작합니다([호스트 문서](../../docs/product/hosts.md)). 다른 호스트의 비대화형 호출은 그 호스트의 공식 문서에서 확인하세요.

3. 조건마다 잽니다.

   ```bash
   python3 -I scripts/prose_calibration.py --outputs /tmp/out-baseline --label baseline \
     --reference evals/prose/katfish-reference.json > baseline.json
   ```

4. 두 조건의 JSON을 갈래별로 견줍니다. `--label`은 사용자가 정한 이름표일 뿐이고, 어떤 하네스와 모델이 실제로 돌았는지는 이 도구가 확인하지 않습니다.

## 결과를 읽는 법

- `registers.<갈래>.median_score`와 `pass`는 그 갈래 출력의 점수 중앙값과 90·75·60점 이상 비율입니다. `katfish`가 붙은 갈래는 KatFish 사람 글의 같은 값이 옆에 나옵니다. 일상 글(`everyday`)은 사람 글 자료가 없어 비교값이 없습니다.
- `polish`는 윤문 프롬프트만의 값입니다. 원문 점수(`median_source_score`)와 윤문본 점수(`median_polished_score`)를 견주고, `fidelity_blocked`는 수치·인용·URL·코드가 바뀐 윤문의 수입니다. 이 숫자가 0이 아니면 점수가 좋아도 윤문이 사실을 건드린 것입니다.
- `top_rules`는 출력의 몇 퍼센트에서 그 규칙이 걸렸는지입니다. 새 버릇을 쓰는 모델은 여기서 점수에 드러나지 않는 패턴을 찾을 단서를 얻습니다.

## 해석할 때 조심할 것

- 갈래별 출력이 5~10개라 표본이 작습니다. 점수 차이가 몇 점이면 우연으로 볼 만하고, 등급이 한 단계 이상 벌어지거나 차단 신호가 갈리는 정도를 신호로 봅니다.
- 점수는 목록에 있는 버릇의 밀도입니다. 목록에 없는 버릇은 점수에 드러나지 않으므로 높은 점수가 사람 같은 글이라는 뜻은 아닙니다.
- KatFish 사람 글의 에세이는 초중고 학생 글, 초록은 짧은 초록입니다. 어른의 업무 글과 비교해 쓰지 마세요.
- 보류해 둔 규칙이 있습니다. 최신 모델이 즐겨 쓴다는 두 문장 대구(`X가 아닙니다. Y입니다.`)는 KatFish에서 신호가 약해(사람 0/91, LLM 7/295) 넣지 않았습니다. 이 절차로 모은 출력의 `details`에서 같은 패턴이 흔한지 보고 그때 다시 판단하세요.

## 파일

| 파일 | 내용 |
| --- | --- |
| `prompts.json` | 고정 프롬프트 26개. 윤문 프롬프트에는 원문(`source`)과 손으로 고친 기준 문장(`gold`)이 들어 있습니다. `gold`는 모델에게 보내지 않으며 시험이 검사기와 어긋나지 않는지 확인하는 데만 씁니다. |
| `katfish-reference.json` | KatFish 사람·LLM 글의 갈래별 집계입니다. 원문은 들어 있지 않습니다. 라이선스를 확인하지 못해 집계 수치만 두었습니다. |
