# 문체 점수 실측 절차 (모델 출력)

`prose` 점수가 Gemini가 실제로 작성한 한국어에서 어떻게 나타나는지 측정하는 절차입니다. 3.3.0까지 이 저장소에 **Gemini 출력으로 실측한 값은 없습니다.** 점수 기준을 맞춘 자료는 KatFish(사람 글과 2024년 LLM 글)뿐이며, 개발 환경에 Gemini CLI와 API 키가 없어 이 절차를 직접 실행하지는 못했습니다. 아래 도구는 사용자가 한 번 수집한 모델 출력을 오프라인에서 측정하기 위한 용도입니다.

## 쿼터

프롬프트는 26개이며 윤문 6개가 포함되어 있습니다. 조건 하나(예: GTG 없음, GTG 있음)마다 26번 호출하시면 됩니다. 점수 계산 과정은 모델을 부르지 않으므로 몇 번을 반복 측정하더라도 쿼터를 소모하지 않습니다. 동일한 조건을 반복하여 측정하는 것은 권장하지 않습니다. 원하는 결과가 나올 때까지 반복하면 객관적 측정이 아닌 편향된 선택이 되기 때문입니다.

## 절차

1. 프롬프트를 파일로 추출합니다. 이 과정에서 모델은 호출되지 않습니다.

   ```bash
   python3 scripts/prose_calibration.py --export-prompts /tmp/prose-prompts
   ```

2. `/tmp/prose-prompts/<id>.prompt.txt`의 내용을 각 실험 조건마다 한 번씩 모델에 전달하고, 응답 본문만 `<폴더>/<id>.md`로 저장합니다. 인사말이나 도구 호출 기록이 섞이면 점수가 달라지므로 순수 본문만 남겨 주십시오. Antigravity CLI는 헤드리스 모드(`agy -p`)에서 `--add-dir`로 작업공간을 지정해야 훅이 동작합니다([호스트 문서](../../docs/product/hosts.md)). 다른 호스트의 비대화형 호출 방식은 해당 호스트의 공식 문서를 확인해 주십시오.

3. 각 조건별로 점수를 계산합니다.

   ```bash
   python3 -I scripts/prose_calibration.py --outputs /tmp/out-baseline --label baseline \
     --reference evals/prose/katfish-reference.json > baseline.json
   ```

4. 두 조건의 결과 JSON을 갈래별로 대조합니다. `--label`은 사용자가 부여한 식별용 라벨일 뿐이며, 어떤 하네스와 모델이 실제로 실행되었는지는 이 도구가 판별하지 않습니다.

## 결과를 읽는 법

- `registers.<갈래>.median_score`와 `pass`는 해당 갈래 출력의 점수 중앙값과 90·75·60점 이상 달성 비율입니다. `katfish`가 붙은 갈래는 KatFish 사람 글의 동일한 측정치가 나란히 표시됩니다. 일상 글(`everyday`)은 사람 글 원천 데이터가 없어 비교 수치가 제공되지 않습니다.
- `polish`는 윤문 프롬프트만의 집계값입니다. 원문 점수(`median_source_score`)와 윤문본 점수(`median_polished_score`)를 견주며, `fidelity_blocked`는 수치나 인용구, URL, 코드가 훼손된 윤문 건수입니다. 이 수치가 0이 아니라면 점수가 높더라도 윤문이 객관적 사실을 변조한 것입니다.
- `top_rules`는 출력의 몇 퍼센트에서 해당 규칙이 감지되었는지를 나타냅니다. 새로운 문체 버릇을 쓰는 최신 모델의 경우, 점수에 드러나지 않는 미지의 패턴을 파악할 중요한 단서가 됩니다.

## 해석할 때 주의할 점

- 갈래별 출력이 5~10개 수준이어서 표본 크기가 작습니다. 몇 점 정도의 미세한 점수 차이는 우연일 가능성이 높으므로, 등급이 한 단계 이상 벌어지거나 차단 항목의 유무가 갈리는 양상을 주된 비교 기준으로 삼습니다.
- 점수는 사전에 등록된 규칙 목록에 존재하는 버릇의 밀도입니다. 목록에 없는 새로운 버릇은 점수에 반영되지 않으므로 높은 점수가 곧바로 사람이 쓴 듯한 자연스러운 글을 뜻하지는 않습니다.
- KatFish 사람 글의 에세이는 초중고 학생 글이며 초록은 짧은 요약문입니다. 성인의 전문적인 업무 문서와 직접 비교하는 용도로 사용하지 마십시오.
- 보류해 둔 규칙이 존재합니다. 최신 모델이 즐겨 쓴다는 두 문장 대구(`X가 아닙니다. Y입니다.`)는 KatFish 데이터셋에서 발생 빈도가 낮아(사람 0/91, LLM 7/295) 정식 규칙에 넣지 않았습니다. 이 절차로 수집한 출력의 `details`에서 동일한 패턴이 빈번하게 관측되는지 확인하신 뒤 반영 여부를 판단해 주십시오.

## 파일

| 파일 | 내용 |
| --- | --- |
| `prompts.json` | 고정 프롬프트 26개입니다. 윤문 프롬프트에는 원문(`source`)과 사람이 손으로 다듬은 기준 문장(`gold`)이 수록되어 있습니다. `gold`는 모델에게 전달하지 않으며 시험이 검사기와 어긋나지 않는지 점검하는 용도로만 사용합니다. |
| `katfish-reference.json` | KatFish 사람 글과 LLM 글의 갈래별 통계 집계표입니다. 원문 텍스트는 포함되어 있지 않습니다. 라이선스 확인 한계로 인해 가공된 집계 수치만 수록했습니다. |
