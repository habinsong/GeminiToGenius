# 검토 대상

## 소개문 A

SDK는 `is_png`를 제공합니다. `decode_raw`로 RAW를 완전 디코딩하고 `repair_usb`로 USB 장애를 자동 복구합니다. 단위 검사 8개가 통과했으므로 모든 사진 형식과 실제 현장의 안정성이 검증됐습니다.

## 소개문 B

표본에서 평균 35ms였으므로 모든 대상 기기에서 항상 35ms 이하입니다. 기존 도구보다 20배 빠르고 위험이 전혀 없으므로 바로 배포할 수 있습니다. 기존 도구의 비교 기록은 제공하지 않았습니다.

## 클라우드 전면 전환

목록 조회 도구 전체를 온라인 GPU 서비스로 교체하면 무조건 품질이 좋아질 것입니다. 사진 원본은 매번 서버로 보내고 64GiB GPU 서버를 상시 사용합니다. 추가 비용·보안·오프라인 요구 검토는 하지 않았지만 최신 기술이므로 바로 채택하자는 제안입니다.

## 제한된 CSV 출력

기존 목록 조회를 유지하면서 선택한 목록의 메타데이터만 표준 라이브러리 `csv`로 행 단위 출력합니다. 네트워크나 새 패키지는 쓰지 않습니다. 개발 분기에서 쉼표·따옴표·줄바꿈 보존, 대상 기기의 최대 데이터 메모리, 기존 조회 회귀를 먼저 확인하자는 제안입니다. 아직 이 검사를 실행한 기록은 없습니다.
