# 검토용 가상 프로젝트

이 폴더는 평가를 위한 가상 제품입니다. 수치·SDK·시험 기록은 이 사례의 입력이며 실제 제품이나 실측 결과가 아닙니다. 외부 제품 지식으로 빈칸을 채우지 마세요.

제품은 인터넷 없는 현장의 사진 목록을 조회하는 도구입니다. 현재 목표는 목록 조회 유지이며 클라우드 전환은 요구되지 않았습니다. 실제 배포 제약과 시험 조건은 `evidence.md`, 검토할 제안은 `proposals.md`, 이전 메모는 `memo.md`에 있습니다. 사용자 요청에 지정한 항목만 검토합니다.

`sdk.py`가 이 사례에서 제공하는 SDK의 전체 구현입니다. 다른 모듈이나 비공개 API는 제공하지 않았습니다. CSV 출력은 표준 라이브러리 `csv`로 한 행씩 내보내는 선택적 기능으로 검토 중이며, 구현·배포 승인은 아직 없습니다.
