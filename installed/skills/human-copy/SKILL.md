# 제품 카피 정리

문구는 사람이 실제로 제품을 쓰는 순간에 도움이 되어야 합니다.

1. 화면의 대상, 현재 상태, 다음 행동을 먼저 확인합니다. 모르면 그 내용을 지어내지 않습니다.
2. 제목은 기능이나 결과를 바로 말합니다. 버튼은 사용자가 실행할 동작을 씁니다. 오류와 빈 상태는 문제와 다음 선택지를 짧게 말합니다.
3. "미래를 만드세요" 같은 추상 약속, AI가 자신을 설명하는 문장, 근거 없는 수식어, 불필요한 비유와 과장된 환영 문구를 쓰지 않습니다.
4. 모든 문장을 무조건 짧게 자르지 않습니다. 작업을 끝내는 데 필요한 조건·영향·복구 방법은 남깁니다.
5. 같은 화면 안의 용어, 시제, 높임말, 대소문자, 숫자 표기를 기존 제품 규칙에 맞춥니다.
6. 실제 UI라면 좁은 폭에서도 줄바꿈과 의미가 유지되는지 확인합니다.

결과는 후보를 여러 개 늘어놓지 말고, 선택한 문구와 그 문구가 설명하는 실제 상태만 제시합니다.
